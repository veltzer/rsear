# rsear

RSEar, an ear training program written in Rust.

RSEar plays musical sequences through FluidSynth and shows what is being
played in real time on a grand staff, a piano keyboard and as note names, so
you can connect what you hear with what you see.

Full documentation lives in the `docs/` mdBook and is published at
<https://veltzer.github.io/rsear>.

## Quick start

```bash
cargo install --path .
rsear
```
